# Описание лабы, что и как сделано

В лабе реализован алгоритм для парсинга командной строки и удаления файлов с определенным префиксом указанного размера.
Скрипт поддерживает рекурсивный спуск по файлам и dry-run режим, чтобы просмотреть файлы, а не сразу удалять их.
В начале скрипта задана настройка, чтобы программа падала при первой ошибке, а не продолжала всеми силами выполняться.

Краткая сводка по алгоритму:
- заданы основыне переменные и цвета для красивого вывода
- имеется вывод справочной информации
- функция parse_args парсит аругменты и записывает их в глобальные переменные
- функция validate, очевидно, валидирует спаршенную строку на наличие префикса, максимального размера, директории и тд
- в функции main вызываются все вышеуказанные функции, идет обработка команды и поиск (в dry режиме) и удаления файлов
- нашел прикольную штуку для оптимизации работы для linux и macos
