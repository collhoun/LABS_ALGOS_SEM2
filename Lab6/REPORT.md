# Лабораторная работа №6: Скрипт удаления файлов по префиксу и размеру

## Цель работы

Разработать скрипт на языке Bash, который позволяет удалять файлы с указанным префиксом имени, размер которых находится в заданном диапазоне. Скрипт должен поддерживать рекурсивный поиск, dry-run режим и предоставлять подробную информацию о выполняемых действиях.

## Описание скрипта

Скрипт `main.sh` реализует функциональность удаления файлов на основе следующих параметров:
- Префикс имени файла (обязательный параметр)
- Минимальный размер файла в байтах (включительно, по умолчанию 0)
- Максимальный размер файла в байтах (включительно, обязательный параметр)
- Директория для поиска файлов (обязательный параметр)
- Опция рекурсивного поиска в поддиректориях
- Опция dry-run для предварительного просмотра без удаления

## Реализация

### Структура скрипта

1. **Парсинг аргументов командной строки**: Функция `parse_args()` обрабатывает параметры с помощью конструкции `case` и устанавливает соответствующие переменные.

2. **Валидация входных данных**: Функция `validate()` проверяет корректность всех параметров:
   - Обязательность префикса, максимального размера и директории
   - Существование указанной директории
   - Корректность числовых значений размеров
   - Логическая корректность диапазона (min ≤ max)

3. **Основная логика**: Функция `main()` выполняет поиск и удаление файлов:
   - Использует команду `find` для поиска файлов с заданным префиксом
   - Определяет размер файла с помощью `stat` (кросс-платформенно для GNU и BSD версий)
   - Проверяет соответствие размера заданному диапазону
   - Выводит информацию о найденных/удаленных файлах с цветовым оформлением

### Особенности реализации

- **Кросс-платформенность**: Скрипт работает на Linux (GNU stat) и macOS (BSD stat)
- **Безопасность**: Используется `set -euo pipefail` для строгого режима выполнения
- **Обработка ошибок**: Все ошибки отображаются с цветовым выделением
- **Информативность**: Подробный вывод параметров поиска и результатов работы

## Использование

```bash
./main.sh [OPTIONS] <директория>

Опции:
  -p, --prefix <PREFIX>   Префикс имени файла (обязательно)
  -m, --min <BYTES>       Минимальный размер в байтах (по умолчанию: 0)
  -M, --max <BYTES>       Максимальный размер в байтах (обязательно)
  -r, --recursive         Рекурсивный поиск в поддиректориях
  -d, --dry-run           Показать файлы без удаления
  -h, --help              Показать справку
```

### Примеры использования

```bash
# Удалить файлы с префиксом "tmp_", размером от 1KB до 1MB в директории /test_data
src/main.sh -p "tmp_" -m 1024 -M 1048576 ../test_data

# Просмотреть файлы с префиксом "log_", размером до 5KB с рекурсивным поиском
src/main.sh -p "log_" -M 5000 -r --dry-run ./test_data

# Удалить файлы с префиксом "tmp_", размером от 1000 до 10000 байт в директории ./test_data (на основе тестовых данных)
src/main.sh -p "tmp_" -m 1000 -M 10000 ./test_data

# Просмотреть все файлы с префиксом "log_", размером до 10000 байт с рекурсивным поиском в ./test_data
src/main.sh -p "log_" -M 10000 -r --dry-run ./test_data

# Удалить файлы с префиксом "tmp_", размером от 512 байт до 5000 байт без рекурсии в ./test_data
src/main.sh -p "tmp_" -m 512 -M 5000 ./test_data

# Просмотреть файлы с префиксом "log_", размером от 1000 до 10000 байт с рекурсивным поиском в ./test_data
src/main.sh -p "log_" -m 1000 -M 10000 -r --dry-run ./test_data

# Удалить файлы с префиксом "tmp_", размером до 100000 байт (все tmp_ файлы) в ./test_data
src/main.sh -p "tmp_" -M 100000 ./test_data
```
