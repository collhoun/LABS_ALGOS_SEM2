# Отчет по лабораторной работе №5

## Введение

Целью данной лабораторной работы является реализация структуры данных для представления графа в виде списка ребер и алгоритма нахождения кратчайших путей между всеми парами вершин — алгоритма Флойда-Уоршелла. Кроме того, были реализованы дополнительные функции для работы с графом, включая проверку на наличие циклов, а также проведено тестирование с использованием фреймворка GTest и бенчмаркинг производительности.

Проект написан на языке C с использованием CMake для сборки. Для тестирования используется Google Test.

## Реализация структуры данных

### Список ребер (Edge Array)

Для представления графа используется структура данных "список ребер" (edge list), реализованная в файлах `edge_array.h` и `edge_array.c`.

Структура `Edge` представляет собой ребро графа:
```c
typedef struct Edge {
    int src;      // вершина-источник
    int dest;     // вершина-назначение
    int weight;   // вес ребра
} Edge;
```

Функция `create_array(int size)` выделяет память под массив ребер заданного размера.

### Матрица смежности

Для удобства работы алгоритма Флойда-Уоршелла список ребер преобразуется в матрицу смежности с помощью функции `create_matrix(int size, int num_edges, Edge *edges)`. Функция создает двумерный массив размером `size x size`, где `size` — количество вершин в графе. Матрица инициализируется нулями, затем заполняется весами ребер из массива. Нулевые значения соответствуют отсутствию ребра между вершинами.

Дополнительные функции для работы с матрицей:
- `print_matrix(int size, int **matrix)` — вывод матрицы на экран
- `free_matrix(int **matrix, int size)` — освобождение памяти, занятой матрицей

## Реализация алгоритма Флойда-Уоршелла

Алгоритм Флойда-Уоршелла реализован в функции `FloydWarshall(int size, int **matrix)`. Функция принимает размер графа и исходную матрицу смежности, возвращает матрицу кратчайших расстояний между всеми парами вершин.

Алгоритм работает по принципу динамического программирования:
1. Создается копия исходной матрицы, где отсутствующие ребра заменяются на бесконечность (`INT_MAX`)
2. Для каждой промежуточной вершины `k` от 0 до `size-1`:
   - Для каждой пары вершин `i`, `j`:
     - Если путь через вершину `k` короче текущего пути от `i` к `j`, обновляется расстояние

Временная сложность алгоритма — O(n³), где n — количество вершин.

## Дополнительные функции

### Проверка на наличие циклов

Функция `is_cycled(int **matrix, int size)` проверяет граф на наличие циклов с помощью алгоритма DFS (поиск в глубину). Функция возвращает 1, если в графе найден цикл, и 0 в противном случае.

Алгоритм использует массив `visited` для отслеживания состояния вершин:
- 0 — не посещена
- 1 — посещается (в текущем пути DFS)
- 2 — полностью обработана

Если при обходе обнаруживается вершина, которая уже посещается в текущем пути, значит найден цикл.

Реализованы вспомогательные функции:
- `dfs_recursive(int v, int vertices_number, int *visited, int **matrix)` — рекурсивный обход в глубину
- `dfs(int **matrix, int vertices_number)` — инициализация и запуск DFS для всех компонент связности

## Тестирование

Тестирование выполнено с использованием фреймворка Google Test. Тесты находятся в файле `tests/test.cpp`.

### Тесты структуры Edge Array:
- `CreateArray` — проверка корректного выделения памяти под массив ребер

### Тесты работы с графом:
- `CreateMatrix` — проверка преобразования списка ребер в матрицу смежности

### Тесты алгоритма Флойда-Уоршелла:
- `FloydWarshall` — проверка корректности нахождения кратчайших путей на примере графа из 3 вершин

### Тесты проверки на циклы:
- `IsCycledAcyclic` — проверка ациклического графа
- `IsCycledCyclic` — проверка графа с циклом
- `IsCycledSelfLoop` — проверка графа с петлей (само-ребро)
- `IsCycledDisconnectedCyclic` — проверка несвязного графа с циклом в одной компоненте

Все тесты проходят успешно, что подтверждает корректность реализации.

## Бенчмаркинг

Бенчмаркинг проведен с использованием собственной реализации на C++ (файл `simple_benchmark.cpp`), которая использует высокоточное измерение времени с помощью `std::chrono::high_resolution_clock`.

- ОС: Windows 11

Как видно из результатов, время выполнения алгоритма Флойда-Уоршелла растет кубически (O(n³)), что соответствует теоретической сложности. Для графов небольшого размера (до 100 вершин) время выполнения остается в пределах микросекунд/миллисекунд.

Проверка на циклы выполняется значительно быстрее, что объясняется линейной сложностью DFS относительно количества ребер и вершин.
